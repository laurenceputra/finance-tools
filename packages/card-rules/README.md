# Card rules

`resolveCategory(merchant, settings, card)` applies escaped/exact rules before case-insensitive exact rules, then escaped wildcard patterns in map insertion order. Wildcards do not match literal `*`. Maybank's source default is Local for merchants ending SGP, otherwise Forex; UOB uses the configured default or Others.

`evaluateMonthly(card, transactions, settings, capturedAt)` returns integer SGD category totals, eligible spend and remaining caps for shared rolling three-UTC-calendar-month retention (month-end clamped). Monthly totals still use Singapore posting-calendar months. Pass deduplicated `aggregateCardHistory` transactions, not flattened overlapping snapshots. Only selected categories qualify. UOB Lady's Solitaire has a 75,000-cent cap per category; Maybank XL has a combined 100,000-cent cap. Credits reduce spending. No points/miles or issuer eligibility guarantee is implied. `RULES` explicitly marks both source-derived fixtures **UNVERIFIED**, with unknown effective date and version `legacy-source-fixture-v1`; these are not issuer-confirmed policies. Completeness and debit-only Maybank warnings must remain visible in consumers.

An optional fifth argument `{ ambiguousMonths: history.ambiguousMonths, coverage: history.coverage }` carries history ambiguity into rule evaluation. All results have `incomplete: true` and source/rule warnings. `remainingMinor` is **null** for snapshot-local Maybank ambiguity and the partial oldest retention month: consumers must suppress remaining-cap UI for these months. Other results are observed-data estimates with explicit incomplete coverage, never exact issuer remaining caps. Settings are runtime-validated; no more than two selected categories are accepted.
